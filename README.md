# VaR Model Validation

A Python-based market risk project comparing and validating Value-at-Risk (VaR) and Expected Shortfall (ES) models.

## Methods

### VaR
- Historical VaR
- Parametric VaR
- Monte Carlo VaR
- GARCH VaR

### Expected Shortfall
- Historical ES
- Parametric ES
- Monte Carlo ES
- GARCH ES

### Backtesting
- Rolling VaR backtesting
- Kupiec test
- Christoffersen test

## Tools

- Python
- NumPy
- Pandas
- SciPy
- Matplotlib
- Statsmodels
- Jupyter
